Som do PC no tablet e microfone do tablet no PC.

- Microfone do tablet no PC: no menu da sessão (toque com três dedos), "Ligar microfone". No Windows ele aparece como "CABLE Output (VB-Audio Virtual Cable)"; escolha esse microfone no Meet, Discord ou Teams. Começa mudo em toda sessão (a opção "Microfone ligado ao conectar" muda isso) e para quando o app vai para segundo plano. Na primeira vez o tablet pede a permissão do microfone.
- O PC precisa do VB-CABLE, instalado uma vez como administrador: `powershell -ExecutionPolicy Bypass -File C:\gr\tools\setup\instalar-audio.ps1`.
- Caixas do PC em silêncio durante a sessão com "Reproduzir áudio no PC" desligado (o padrão): o som vai só para o tablet, pelo Steam Streaming Speakers.
